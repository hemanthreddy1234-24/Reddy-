# EventSupply - Interactive Event Material Website

## Five files
1. index.html - website structure
2. style.css - responsive design
3. script.js - materials, modal, cart, booking and payment-method interaction
4. README.md - instructions
5. LICENSE - MIT license

## Included functionality
- Interactive details for every material
- Quantity selection
- Add to cart
- Increase/decrease quantity
- Remove items
- Automatic total calculation
- Customer booking form
- Event date
- UPI, card, net banking and pay-on-delivery payment method selection
- Responsive mobile layout

## Important payment note
This version contains a payment-method UI and demo checkout flow. It does NOT process real money. For production payments, connect a trusted gateway such as Razorpay/Stripe through a secure backend and never collect or store raw card/CVV data in this front-end.

## Run
Extract the ZIP and open index.html in a modern browser.
